# 护教回答模板说明（_template）

本目录是**护教子数据库的填写模板**，供内容编辑者复制使用。`_template` 不会被构建（构建只遍历 `content.meta.json` 的 `topics` 列表），可放心保留。

## 目录内容

```
_template/
├── topic.json                      主题模板（新增主题时复制为 <主题id>/topic.json）
└── your-question/                  子问题目录模板（新增子问题时复制为 <主题id>/<子问题id>/）
    ├── question.json               子问题模板
    └── your-response.json          回答模板 ★（新增回答时复制为 <回答id>.json）
```

## 快速上手：新增一个回答（三步）

1. **复制**：把 `your-response.json` 复制到目标子问题目录（如 `topics/suffering/evil/`），改名为 `<回答id>.json`（如 `eternal-perspective.json`）。
2. **填写**：按下方写作规范填写全部字段（id 必须与文件名一致）。
3. **登记顺序**：把回答 id 追加到同目录 `question.json` 的 `responses` 列表末尾 → 运行 `npm run data` 即可上线。

## 回答写作规范

| 要点 | 说明 |
|---|---|
| 立场 | 目标是"帮助人理解基督信仰为何具有合理性"，不是"赢得辩论"——尊重提问者，诚实面对，不回避、不嘲讽 |
| 结构 | 三段式：① 承认问题的合理性 / 区分概念（如"需要区分两种进化论"）；② 正面回应（论证、事实或经文）；③ 指向盼望、行动或邀请（十字架、证据、继续探索） |
| 篇幅 | 正文 150–300 字为宜；summary 一句话（30 字内）；标题 8 字内 |
| 语气 | 中文书面语，清晰平和；适度引用经文（全称"书卷 章:节"），可引哲学/历史/科学证据 |
| 视角徽章 | perspective 用于区分回答间的不同立场（哲学视角 / 圣经视角 / 历史学视角 / 牧养视角…） |
| 标题 | title.zh 概括该回答的核心主张（如"自由意志回应"），title.en 给出对应英文（如 Free Will Defense） |

## 证据填写指南（evidence）

每个回答**至少一条圣经引用**（bible），其余按论证需要补充，类别固定七种：

| key | 内容 | 示例 |
|---|---|---|
| `bible` | 经文（ref 必须形如"书卷 章:节"，可跳转读经研究） | `{ "ref": "罗马书 8:18", "note": "现在的苦楚不足介意。" }` |
| `philosophy` | 哲学家/著作/论证 | `{ "ref": "C.S. 路易斯《人之废》", "note": "道德律论证。" }` |
| `history` | 历史事件/史料/出土物 | `{ "ref": "死海古卷", "note": "与马所拉文本相隔千年而高度吻合。" }` |
| `science` | 科学事实/理论 | `{ "ref": "宇宙微波背景辐射 1965", "note": "大爆炸的直接证据。" }` |
| `theology` | 神学观点 | `{ "ref": "路德：同时是义人，也是罪人", "note": "教会的双重性。" }` |
| `ethics` | 伦理依据/道德直觉 | `{ "ref": "普世道德直觉", "note": "虐杀婴儿为客观错误。" }` |
| `literature` | 文献学证据 | `{ "ref": "教父引文覆盖全新约", "note": "即使抄本失传也能重建。" }` |

注意：
- `ref` 应**具体可查**（出处/名称），`note` 一句话说明它与回应的关系（约 20 字内）。
- 圣经引用不要虚构出处——先查证经文原文再写 note。
- 没有证据的类别**省略不写**（留空数组也不会报错，但不应出现）。
